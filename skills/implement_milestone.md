# Skill: Implement Next Milestone

**Objective:** Autonomously implement the next pending milestone for the Highland Cal project, open a Pull Request, and update the project tracking state.

## Execution Steps:
1. **Read State:** View the `docs/STATUS.md` file to identify the `Current Milestone`.
2. **Read Spec:** View the `docs/Roadmap.md` file and navigate to the section for the `Current Milestone`.
3. **Plan:** Read all the tasks for that milestone. Create an Implementation Plan and wait for user approval.
4. **Implement:** Execute the implementation plan. 
5. **Verify:** Ensure the codebase runs locally and passes linting/type-checking (if configured).
6. **Update Progress:** 
   - Edit `docs/Roadmap.md` to check off the completed `[x]` tasks for this milestone.
   - Edit `docs/STATUS.md` to increment the `Current Milestone` to the next logical phase.
7. **Finalize:** Summarize your changes and instruct the user to commit the code and open a Pull Request.
